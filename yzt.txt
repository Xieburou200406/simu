[] 一.系统介绍
[] （一） 定价模型
[] 1. 期权定价合约（Driver，)
[] 定价合约是给期权定价的标的合约。定价合约可以为期货合约，现货合约，或者合成合约。
[] 1.1 中金所上市期权品种
[] 中金所上市的期权品种（MO，IO，HO）有对应的期货，我们采用期货主力合约作为中金所上市期权的定价合约。
[] 1.2 上交所和深交所上市期权品种
[] 上交所和深圳所上市的ETF期权品种，有一些ETF的价格变化和中金所期货价格变化高度相关（如510050，159915和IH期货合约相关；510500，1599922和IC期货合约相关，510300，159919和IF期货合约相关），并且期货合约行情更新频率远远高于ETF的价格更新频率，因此我们采用相关期货主力合约作为期权定价合约。其余的ETF因为找不到相对应的期货合约，因此我们采用该ETF作为期权定价合约。
[] 1.3 商品交易所上市期权品种
[] 商品交易所上市的期货期权品种和中金所上市的期权品种类似，我们都采用对应期货主力合约作为上市期权的定价合约。
[] 1.4 合成合约
[] 将互相关联合约的行情信息，通过一定的策略算法合成一个新的价格来为相关期权定价。比如510050合约一档行情3秒更新一次。两次行情更新之间交易所发布逐笔委托和逐笔成交数据。我们根据第一次行情更新建立起一个订单队列，然后根据逐笔委托/成交更新订单队列，从而得到（估算）最新的市场行情，即合成合约。我们可将该“合成合约”命名为999050并给510050期权合约定价。用来生成”合成合约“的行情包括期货合约一档/五档行情；现货合约一档/五档/逐笔成交委托行情；ETF或者指数成分股按照既定规则合成的价格。
[] 2. 隐含远期价格（Implied Forward,)和隐含基差（Implied Basis,)
[] 期权市场自身有一个隐含远期价格：不同期权品种的不一样，同一品种不同到期日的期权也不一样。为了给期权合约定价，我们可以通过特定的算法从市场上算出每组到期日期权的，所以该组到期日期权对应的隐含基差为。不难看出在短时间内有均值回归的特性，因此我们通过指数移动平均（EMA）的方式过滤掉中的噪音，即。可以作为该月份期权合约提供稳定的定价。

[] （二）波动率曲线拟合模块
[] 1. 基差拟合模块
[] 隐含基差和隐含波动率一样，是期权定价绕不开的话题。一些交易员使用不同的波动率曲线分别给认购期权和认沽期权定价（即认沽期权和认购期权的波动率曲线不同），就是他们忽略了隐含基差，用标的的价格直接去计算期权隐含波动率导致的。
[] 2. 不同的拟合方式
[] 在系统中波动率拟合需要用到的参数，拟合的结果都呈现在ExpVol这个界面，
[] 其中隐含基差和波动率曲线可以选择手动设置模式或自动拟合模式,不同品种不同到期月独立选择。
[] BssMode: 隐含基差模式Manual为手动设置，Smooth为系统自动拟合。
[] AutoMan: Y选择将拟合出最新的波动率曲线更新给(M.Bss,M.Vol,M.Sml,M.KtC,M.KtP)；N为不会更新。
[] CFPanic: 在曲线拟合时某个参数在两个时刻间的差大于设定的jump值，该开关会自动从N跳为Y，同时CFmode也会跳为Manual。同时当显示Y时无法打开交易开关，所以常态应保持为N。
[] CFMode: 选择是否使用自动拟合模型，选择Manual，会将交易员手动设置的隐含波率曲线赋值给(U.Bss,U.Vol,U.Sml,U.KtC,U.KtP)。选择FitPx会将平滑后的曲线赋值给(U.Bss,U.Vol,U.Sml,U.KtC,U.KtP)
[] KurtMode: 包含OneKurt和TwoKurt，OneKurt认购和认沽期权使用一个Kurtosis，即Ktc=Ktp；TwoKurt认购和认沽期权使用不同的Kurtosis，即Ktc！=Ktp。
[] CFReset: 点击后系统模型根据最新的市场的行情拟合波动率曲线。

[] 4. 合约的选择条件
[] 当筛选合约用于波动率曲线拟合时，系统根据预设参数进行精确选择
[] Min.Imp.Delta:选取用于拟合合约最小delta绝对值； Max.Imp.Delta:选取用于拟合合约最大Delta绝对值
[] C.Imp.Num:选取用于拟合的认购期权最大个数；P.Imp.Num:选取用于拟合的认沽期权最大个数
[] 在选择合约时，对于认购期权，只有当其Delta值处于Min.Imp.Delta和Max.Imp.Delta之间，并且在平值期权加上C.Imp.Num个认购期权的范围内，才会被选为用于拟合的合约。
[] 同样地，对于认沽期权，只有当其Delta值的绝对值处于Min.Imp.Delta和Max.Imp.Delta之间，并且在平值期权加上P.Imp.Num个认沽期权的范围内，才会被选为用于拟合的合约。
[] 一旦合约被选择用于波动率曲线拟合，OptMain中的AIS（Auto Implication Selected）将显示为"Y"，如下图所示。
[] 其中Delta的选取范围为0.5到50，认购合约和认沽合约最多各选6个。因此3250Put的delta的绝对值小于0.5，未被做为用于拟合的合约。
[] 5. Jump功能介绍
[] 该组参数指在波动率曲线拟合过程中，最新一次拟合跟上一次拟合所使用的参数数据之间绝对值差值如果大于对应参数的Jump值，则会触发CFPanic，触发CFPanic系统会停止交易，同时CFMode会从FixPx跳为Manual。
[] 6. 拟合的参数设置
[] C.Max.Vol.Mult,P.Max.Vol.Mult是一组乘数，在波动率拟合的时候对vol取值的限制，用ATM期权的隐含波率分别乘以C.Max.Vol.Mult和P.Max.Vol.Mult
[] Call侧曲线Vol ＜ ATM * C.Max.Vol.Mult
[] Put测曲线Vol ＜ ATM * P.Max.Vol.Mult
[] MinStkImF: 最小行权价值； MaxStkImF: 最大行权价值；
[] I.Fwd.Min: 最小远期价格； I.Fwd.Max: 最大远期价格；
[] I.Vol.Min: 最小隐含波动率； I.Vol.Max: 最大隐含波动率；
[] I.Sml.Min: 最小Skew值； I.Sml.Max: 最大Skew值；
[] I.KtC.Min: Call曲线最小Kurtosis值； I.KtC.Max: Call曲线最大Kurtosis值；
[] I.KtP.Min: Put曲线最小Kurtosis值 ；I.KtP.Max: Put曲线最大Kurtosis值；

[] （三）套利交易模块
[] 1. OptMain
[] 1.1 市场价，理论价与仓位
[] 在期权套利交易模块中系统会根据模型计算每个合约的理论价值(cTV)，同时也会根据持仓对每个合约的理论价格进行调整(ArbSSTv)，用调整后的理论价格在市场上寻找满足利润需求的合约进行交易，并实时保持头寸趋近于零。套利交易模块中包含了期权理论价格的计算、下单的功能，在系统界面中显示在OptMain界面中。
[] Instr:期权合约名 Strike: 行权价
[] cTV: 期权理论价 ArbTv: 以cTV为基础根据持仓风险度调整后的理论价格 ArbSSTv: 以ArbTv为基础根据StrikePos调整的理论价格
[] MBS: 市场买一量 MBP: 市场买一价 MAS: 市场卖一量 MAP:市场卖一价
[] CBP: 以理论为基础根据利润参数计算的最优买价 CAP: 以理论为基础根据利润参数计算的最优卖价
[] OBP: 准备发向市场的最优买价 OAP: 准备发向市场的最优卖价
[] SBP: 在途买单价格 SAP: 在途卖单价格
[] ArbPos: 该合约持仓数量 StrikePos: 对应一个行权价的总持仓数量 PosSOD: 开盘时该合约的持仓数量
[] Bias：当买单价格BidPrice > LastPrice + Bias,该买单不会发单。当卖单价格AskPrice < LastPrice - Bias,该卖单不会发单。

[] OpenLimit: 最大开仓数量；

struct VolCurveCut {
    VolCurveCut(double min_vol=0, double max_cal_vol_mult=0, double max_put_vol_mult=0,
                double dc=0, double dsm=0, double uc=0, double usm=0) :
        min_vol(min_vol), max_cal_vol_mult(max_cal_vol_mult), max_put_vol_mult(max_put_vol_mult),
        dn_cut(dc), dsm(dsm), up_cut(uc), usm(usm) {}
    double min_vol;
    double max_cal_vol_mult;
    double max_put_vol_mult;
    double dn_cut;
    double dsm;
    double up_cut;
    double usm;

void XCalcOption::calc_greeks_numeric(double te, double ds, double fd, double sk, double vl, double sl, double kc, double kp, int cp,
                                      const VolCurveCut &cut, int, double fmp, double atm,
                                      double ssr, double vcr, double scr, XCalcOptionGreek *greeks) {

    //const double fwd_move_pct = 0.01;
    const double fwd_move_up = 1.0 + fmp, fwd_move_dn = 1.0 - fmp;
    const double log101 = log(fwd_move_up), log099=log(fwd_move_dn);
    const double sqrtpi = XCalcMath::Sqrt(3.1415926 * 2);
    const double slope = 0;

    double sml_vol, sml_vol_u, sml_vol_d;
    double d, du, dd, pu, pd;
    double sqr_tte, fk_log, zz, zu, zd, atm_log;
    double sl_u, sl_d;

    double delta_u, delta_d;

    if( cp != 0 ) {
        if( hft::greater(te, 0) ) {
            sqr_tte = XCalcMath::Sqrt(te);
            fk_log = XCalcMath::Log(fd / sk);
            atm_log = XCalcMath::Log(atm / sk);

            zz = atm_log / sqr_tte;
            greeks->smile_vol = calc_volatility(vl, sl, kc, kp, zz, sqr_tte, cut);
            sml_vol =  greeks->smile_vol * sqr_tte;
            d = fk_log / sml_vol + sml_vol * 0.5;
            greeks->tv = calc_tv(ds, cp, d, sml_vol, fd, sk);

            zu = log101 / sqr_tte;
            zd = log099 / sqr_tte;
//            sml_vol_u = vl - slope * zu;
//            sml_vol_d = vl - slope * zd;
            sml_vol_u = vl - slope * zu + ssr * vcr * fmp;
            sml_vol_d = vl - slope * zd - ssr * vcr * fmp;

            sl_u = sl + ssr * scr * fmp;
            sl_d = sl - ssr * scr * fmp;

            zu = (log101 + atm_log) / sqr_tte;
            zd = (log099 + atm_log) / sqr_tte;
            sml_vol_u = calc_volatility(sml_vol_u, sl_u, kc, kp, zu, sqr_tte, cut) * sqr_tte;
            sml_vol_d = calc_volatility(sml_vol_d, sl_d, kc, kp, zd, sqr_tte, cut) * sqr_tte;
            du = (log101 + fk_log) / sml_vol_u + sml_vol_u * 0.5;
            dd = (log099 + fk_log) / sml_vol_d + sml_vol_d * 0.5;
            pu = calc_tv(1.0, cp, du, sml_vol_u, fd * fwd_move_up, sk);
            pd = calc_tv(1.0, cp, dd, sml_vol_d, fd * fwd_move_dn, sk);
            greeks->delta = (pu - pd) / fd / (fwd_move_up - fwd_move_dn);

            if( cp == 1 ) {
                if( greeks->delta > 1.0 ) {greeks->delta = 1.0;}
                else if( greeks->delta < 0 ) {greeks->delta = 0.0;}
            } else {
                if( greeks->delta < -1.0 ) {greeks->delta = -1.0;}
                else if( greeks->delta > 0 ) { greeks->delta = 0;}
            }


            if(fk_log > 0) {
                delta_u = cp * XCalcMath::Norm(cp * du ) + exp(-du * du * 0.5) / sqrtpi * ((sl - slope + kp * zu));
                delta_d = cp * XCalcMath::Norm(cp * dd ) + exp(-dd * dd * 0.5) / sqrtpi * ((sl - slope + kp * zd));
            } else {
                delta_u = cp * XCalcMath::Norm(cp * du ) + exp(-du * du * 0.5) / sqrtpi * ((sl - slope + kc * zu));
                delta_d = cp * XCalcMath::Norm(cp * dd ) + exp(-dd * dd * 0.5) / sqrtpi * ((sl - slope + kc * zd));
            }
            greeks->gamma = XCalcMath::Abs( (delta_u - delta_d) * 0.5 * fd * 0.0001 / (fwd_move_up - fwd_move_dn));

            sml_vol_u = calc_volatility(vl + 0.01, sl, kc, kp, zz, sqr_tte, cut) * sqr_tte;
            sml_vol_d = calc_volatility(vl - 0.01, sl, kc, kp, zz, sqr_tte, cut) * sqr_tte;
            du = fk_log / sml_vol_u + sml_vol_u * 0.5;
            dd = fk_log / sml_vol_d + sml_vol_d * 0.5;
            pu = calc_tv(ds, cp, du, sml_vol_u, fd, sk);
            pd = calc_tv(ds, cp, dd, sml_vol_d, fd, sk);
            greeks->vega = (pu - pd) * 0.5;

            greeks->vomma = (pu + pd - 2 * greeks->tv);

            sml_vol_u = calc_volatility(vl, sl + 0.01, kc, kp, zz, sqr_tte, cut) * sqr_tte;
            sml_vol_d = calc_volatility(vl, sl - 0.01, kc, kp, zz, sqr_tte, cut) * sqr_tte;
            du = fk_log / sml_vol_u + sml_vol_u * 0.5;
            dd = fk_log / sml_vol_d + sml_vol_d * 0.5;
            pu = calc_tv(ds, cp, du, sml_vol_u, fd, sk);
            pd = calc_tv(ds, cp, dd, sml_vol_d, fd, sk);
            greeks->vega_skew = (pu - pd) * 0.5;

            if( zz > 0 ) {
                greeks->vega_kurt_c = 0;
                sml_vol_u = calc_volatility(vl, sl, kc, kp + 0.01, zz, sqr_tte, cut) * sqr_tte;
                sml_vol_d = calc_volatility(vl, sl, kc, kp - 0.01, zz, sqr_tte, cut) * sqr_tte;
                du = fk_log / sml_vol_u + sml_vol_u * 0.5;
                dd = fk_log / sml_vol_d + sml_vol_d * 0.5;
                pu = calc_tv(ds, cp, du, sml_vol_u, fd, sk);
                pd = calc_tv(ds, cp, dd, sml_vol_d, fd, sk);
                greeks->vega_kurt_p = (pu - pd) * 0.5;
            } else {
                greeks->vega_kurt_p = 0;
                sml_vol_u = calc_volatility(vl, sl, kc + 0.01, kp, zz, sqr_tte, cut) * sqr_tte;
                sml_vol_d = calc_volatility(vl, sl, kc - 0.01, kp, zz, sqr_tte, cut) * sqr_tte;
                du = fk_log / sml_vol_u + sml_vol_u * 0.5;
                dd = fk_log / sml_vol_d + sml_vol_d * 0.5;
                pu = calc_tv(ds, cp, du, sml_vol_u, fd, sk);
                pd = calc_tv(ds, cp, dd, sml_vol_d, fd, sk);
                greeks->vega_kurt_c = (pu - pd) * 0.5;
            }
        } else {
            if( cp * fd >= cp * sk ) {
                greeks->tv = cp * ( fd - sk );
                greeks->delta = cp;
            } else {
                greeks->tv = 0;
                greeks->delta = 0;
            }
            greeks->gamma = 0;
            greeks->vega = 0;
            greeks->vega_skew = 0;
            greeks->vega_kurt_c = 0;
            greeks->vega_kurt_p = 0;
        }
    }
}

double XCalcOption::calc_smiled_vol(double tte, double fwd, double stk, double vol, double sml,
                              double ktc, double ktp, const VolCurveCut& cut, int) {
    double sqr_tte = XCalcMath::Sqrt(tte);
    double fk_log = XCalcMath::Log(fwd / stk);
    double zz = fk_log / sqr_tte;
    return calc_volatility(vol, sml, ktc, ktp, zz, sqr_tte, cut);
}

void XCalcOption::get_dc_uc_strike(double dc, double uc, double atm, double tte, double &dcstrike, double &ucstrike) {
    dcstrike = exp(dc) * atm;
    ucstrike = exp(uc) * atm;
}

double XCalcOption::calc_volatility(double vol, double sml, double ktc, double ktp, double zz, double sqrt_tte, const VolCurveCut & cut) {
    if( zz < 0 ) {
        return XCalcMath::Max(cut.min_vol, XCalcMath::Min(vol + sml * zz + 0.5 * ktc * zz * zz, vol * cut.max_cal_vol_mult));
    } else {
        return XCalcMath::Max(cut.min_vol, XCalcMath::Min(vol + sml * zz + 0.5 * ktp * zz * zz, vol * cut.max_put_vol_mult));
    }
}

Function bs_sigma(X, F, V, S, K, t)

    zz = Log(F / X) / Sqr(t)
    bs_sigma = V + S * zz + 0.5 * K * zz * zz

End Function

Function bs_d1(X, F, sv, t)

    bs_d1 = Log(F / X) / (sv * Sqr(t)) + 0.5 * sv * Sqr(t)

End Function

Function bs_d2(X, F, sv, t)

    d1 = bs_d1(X, F, sv, t)
    bs_d2 = d1 - sv * Sqr(t)

End Function

Function bs_tv(X, F, V, S, K, t, r)

    sv = bs_sigma(X, F, V, S, K, t)
    
    d1 = bs_d1(X, F, sv, t)
    d2 = bs_d2(X, F, sv, t)
    
    dsf = Exp(-r * t)
    
    bs_tv = dsf * (F * Application.WorksheetFunction.Norm_S_Dist(d1, True) - X * Application.WorksheetFunction.Norm_S_Dist(d2, True))

End Function

Function bs_put(X, F, V, S, K, t, r)

    sv = bs_sigma(X, F, V, S, K, t)
    
    d1 = bs_d1(X, F, sv, t)
    d2 = bs_d2(X, F, sv, t)
    
    dsf = Exp(-r * t)
    
    bs_put = -dsf * (F * Application.WorksheetFunction.Norm_S_Dist(-d1, True) - X * Application.WorksheetFunction.Norm_S_Dist(-d2, True))

End Function

Function bs_delta(X, F, V, S, K, t, r)

    dd = 0.01
    tv_up = bs_tv(X, F + dd, V, S, K, t, r)
    tv_dn = bs_tv(X, F - dd, V, S, K, t, r)
    
    res = (tv_up - tv_dn) / (2 * dd * Exp(-r * t))
    
    bs_delta = Application.WorksheetFunction.Max(0, Application.WorksheetFunction.Min(res, 1))
    
    
End Function


Function bs_vega(X, F, V, S, K, t, r)

    dd = 0.01
    tv_up = bs_tv(X, F, V + dd, S, K, t, r)
    tv_dn = bs_tv(X, F, V - dd, S, K, t, r)
    
    bs_vega = (tv_up - tv_dn) / 2
    
    
End Function


Function bs_skew(X, F, V, S, K, t, r)

    dd = 0.01
    tv_up = bs_tv(X, F, V, S + dd, K, t, r)
    tv_dn = bs_tv(X, F, V, S - dd, K, t, r)
    
    bs_skew = (tv_up - tv_dn) / 2
    
    
End Function

Function bs_kurt(X, F, V, S, K, t, r)

    dd = 0.01
    tv_up = bs_tv(X, F, V, S, K + dd, t, r)
    tv_dn = bs_tv(X, F, V, S, K - dd, t, r)
    
    bs_kurt = (tv_up - tv_dn) / 2
    
    
End Function
